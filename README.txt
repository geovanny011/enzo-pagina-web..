ENZO — Sitio web listo para GitHub Pages

Las fotografías y el logotipo están incrustados directamente dentro de index.html (base64). No necesitas subir una carpeta assets ni enlazar imágenes externas.

Sube index.html, styles.css y script.js a la raíz del repositorio. En GitHub: Settings > Pages > Deploy from a branch > main > /(root).

Antes de publicar, reemplaza el correo y el enlace de Instagram de ejemplo en index.html.
